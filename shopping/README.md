쇼핑 AI agent를 만들고 싶어.
 웹페이지에서 채팅창에 사용자가 원하는 제품을 text로 적으면 해당 제품을 찾아서 리스트 형태로 출력해줘.

조건
- 외부 툴이나 MCP 사용가능
- 사용자가 text로 기술하는 물건과 가장 비슷한 제품 찾기 (비슷한 제품 찾기 위한 방법 연구)
- 찾은 물건 중에 가장 저렴한 제품 찾기 (저렴한 물건 찾기 위한 방법 연구)
- agent 협업으로 구현 (협업 방식에 대한 연구 및 가장 적합한 방식 제안)

기능
1. 상세페이지 검색
   - 사용자의 검색 요구 사항과 제품의 정보가 일치하는지 확인
   - 일치하지 않는 부분이 있거나 애매한 부분이 있다면 playwright를 사용하여 각 페이지 내부의 내용을 검색
   - 세부 내용 검색 agent를 따로 구현
   - 해당 agent는 상세페이지에 접속하여 설명 이미지 및 text의 정보를 분석하여 사용자의 요구사항에 맞는지 확인
   - 사용자의 요구사항과 일치하는 경우, 제품 정보를 반환
   - 사용자의 요구사항과 일치하지 않는 경우, 다시 playwright를 사용하여 각 페이지 내부의 내용을 검색하여 사용자의 요구사항과 일치하는 제품을 찾음
   - 사용자의 요구사항과 일치하는 제품이 없으면 None 반환


향후 추가 개발 계획
- 사용자가 이미지를 올렸을 때 그것과 비슷한 제품 찾기
